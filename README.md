# 🎮 Tienda de Videojuegos (E-Commerce)

Este proyecto es una plantilla de sitio web frontend para una tienda de videojuegos en línea.

## 🚀 Características
- Catálogo de productos interactivo.
- Carrito de compras funcional (añadir productos, ver total y simular checkout).
- Diseño adaptativo con estilo oscuro gamer.

## 🛠️ Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript (Vanilla)

## 📌 Cómo publicar en GitHub Pages
1. Sube los archivos `index.html`, `styles.css` y `script.js` a tu repositorio principal.
2. Ve a **Settings** > **Pages** en GitHub.
3. En la sección **Source**, selecciona la rama `main` (o `master`) y guarda.
4. Tu sitio web estará visible públicamente en unos momentos.
